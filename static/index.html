📘 系统使用手册

使用说明

完整维护版手册支持前端直接查看：点击下面按钮会从 /api/manual 读取 docs/manual.md 并渲染为 Markdown。

一、核心能力

  • 用户与权限：注册/登录、JWT、修改密码、admin/user 角色隔离。
  • 知识库管理：知识库列表、新建、删除、重命名；单文件上传、批量上传、ZIP 上传。
  • 文档浏览：查看文档列表、摘要状态、标签、PDF 是否存在；查看文档详情与中文摘要。
  • 查询与对话：单次查询、纯检索、RAG 问答、多轮 Chat、OpenAI 兼容接口。
  • Agent 模式：Claude Code 驱动，可自主调用 rag_search / rag_ask / rag_list_kbs / rag_list_docs / rag_doc_detail / rag_deep_read。
  • 精读报告：对 PDF 生成 7 维度论文精读报告，支持 SSE 流式和 status 轮询。
  • 文档修改：上传 md/pdf/doc/docx，通过对话修改，自动保存并导出 md/pdf。
  • 论文撰写：论文项目管理、引导对话、AI 大纲、章节解析与兼容章节生成接口。
  • 用量统计：管理员查看各用户、各模块 API 调用量。

二、前端入口

  • 💬 查询知识库：单次查询 / Chat 模式 / Agent 模式。
  • 📚 文档浏览：所有登录用户可浏览文档、摘要、标签与 PDF 状态。
  • ➕ 添加文档、🆕 新建知识库、⚙️ 管理知识库：管理员入口。
  • 📖 精读报告：查看、生成、删除精读报告。
  • ✍️ 论文撰写：创建论文项目、引导收集信息、生成大纲。
  • 📄 文档修改：上传文档并通过 Agent 对话修改。
  • 📊 用量统计：管理员查看 API 调用统计。

四、调用示例

curl -X POST http://localhost:10663/api/search \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"kb":"RVD","query":"VulHawk","top_k":5}'
from openai import OpenAI
client = OpenAI(api_key="YOUR_TOKEN", base_url="http://localhost:10663/api/v1")
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role":"user","content":"什么是二进制代码相似性检测？"}],
)
print(resp.choices[0].message.content)

五、运维提示

  • 服务端口：10663；推荐 systemd 服务名：rag-server。
  • 核心文件：rag_web_server.py、static/index.html、docs/manual.md。
  • 用户数据隔离在 user_data/<username>/；文档修改在 docmod/<username>/。
  • 若 pdf_exists=false，说明有 segments 但 reference PDF 缺失，精读会失败。
  • SSE 端点通过 ?token=YOUR_TOKEN 认证，因为浏览器 EventSource 不能设置 Authorization Header。
  • 更完整的参数、权限、故障排查见 docs/manual.md。
